# A physical threshold with fewer than 9k additional gates

Given k≥1 arbitrary PEqualNP fan-in-two circuits of size at most s on the same inputs and any fixed 1≤t≤k, a circuit of size at most ks+9k−8 computes whether at least t outputs are true. In particular the 3q+1 local parity construction can use this bound with k=3q+1 and t=2q+1.

**Connecting witnesses.** Insert one empty OR gate as a shared false wire. Append the original circuits' gates unchanged apart from input renumbering. An original raw input retains its index. A reference to an existing gate within its own block is translated to the corresponding appended gate. An originally nonexistent or forward reference reads false in the project and is directed to the shared false wire. Translate the chosen output similarly, using its original final extent. Induction on the appended gates proves that each output wire has the same value as in its original circuit, also for a missing output or a gate with zero inputs. There are k·s or fewer copied gates, with no copying operation required for a witness output.

**Compressing one weight.** A half adder on a,b computes their AND and OR, negates the AND, and ANDs the result with their OR. The last wire is XOR, and the first wire supplies the carry. Its cost is four gates. A full adder first uses a half adder on a,b, then a half adder on their XOR and c, then ORs the two carry wires. Its cost is nine. For any row the outputs satisfy the identity sum(a,b,c) = low + 2 carry, and the corresponding two-input identity.

Initially the k outputs all have weight one. In each nonempty weight column, repeatedly compress three wires to one same-weight low wire and one carry reserved for the next column. If exactly two wires remain, use a half adder on them. Record the remaining low output as one count bit. A column of n wires emits exactly floor(n/2) carries. Thus the successive populations are floor(k/2^j), there are B=bit_length(k) columns, and their low bits encode the exact sum. A full adder reduces the total number of pending and recorded wires by one; a half adder preserves their total count. There are exactly k−B full adders. A half adder occurs precisely at a positive even column population, hence precisely at the zero bit positions below the leading one in k. Its count is B−popcount(k).

**Comparing.** Put r=v₂(t). The lowest r threshold bits are zero. At position r the lower threshold is 2^r, so its comparison bit is the r-th data bit itself. Process each successive position j up to B−1. If the threshold bit is one, AND the current data bit with the earlier comparison. If it is zero, take their OR. This uses exactly B−1−r gates and returns whether the full count is at least t. Including the one common false wire, the exact extra cost of the displayed implementation is

    1 + 9(k−B) + 4(B−popcount(k)) + (B−1−r)
      = 9k−4B−4popcount(k)−r ≤ 9k−8.

**Checked scope.** The Mathlib-only module `CounterConservation.lean` proves existence and termination of the column compression, conservation of the exact binary value, the 9k−8 budget given a comparator of at most B−1 gates, and correctness of the one-bit comparison update. Its axiom transcript is in `axioms.log`. The full physical Lean theorem in the separate fleet parity packet uses the fleet's existing unary comparator. The mathematical argument here and the independently constructed actual gate arrays establish the sharper linear compiler at the stated levels of verification.

`python3 check_counter.py` builds physical gate arrays with the project's missing-index semantics. It exhausts 917,506 threshold/row pairs for k≤15, all 135,168 row/threshold combinations of seeded nontrivial source circuits through k=513 (including empty gates and missing or forward references), and gate-count instances through k=10,001. Only the Python standard library is needed.
