# Quantum verification by truth-value queries

Use the reversible oracle mapping |x,b⟩ to |x,b XOR f(x)⟩. Count verifier calls to this oracle, allowing unrestricted other computation. The promise fixes the named essential variables and, for the monotone result, requires f to be monotone. Completeness and soundness are 2/3 and 1/3. Write B(N) for the maximal integer-partition product in `oracle.md`.

For monotone targets the bounded-error quantum query complexity of deciding size at most N−1 is Θ(√B(N)). First run the polynomial-time classical membership-query learner for monotone read-once formulas, cutting it off at its promised-case bound. Reject if it fails to return a valid hypothesis. The union of the minterms and maximal false inputs of that hypothesis has size at most B(N)+N. The verifier can enumerate this set without accessing the oracle. Search it for a disagreement using quantum search with unknown number of marked elements, accepting if none is found. A valid read-once target is identified exactly; any incorrect monotone target has a disagreement on the enumerated set. A classical witness giving the formula permits skipping the learning step. For arbitrary Boolean targets an untrusted classical witness giving a binary read-once formula instead allows quantum search over all 2^N inputs, using O(2^(N/2)) verifier queries. [Boyer, Brassard, Høyer and Tapp, Tight Bounds on Quantum Searching](https://arxiv.org/abs/quant-ph/9605034)

The lower bounds hold even with a quantum witness or an interactive untrusted prover. For a single-point family F, F_I of cardinality M from `oracle.md`, fix an honest prover strategy and witness that achieve completeness on the reference F. Run exactly that strategy on every F_I as a possible dishonest prover. Purify the fixed strategy, verifier operations, measurements and initial side information. Every unitary between oracle calls is now identical in both runs. If the probability on query address I just before query j on F is p_(j,I), changing that one oracle call changes the state norm by at most 2√p_(j,I). A telescoping hybrid, using F for the prefix of the computation and F_I for the suffix, bounds the final state distance by 2∑_j √p_(j,I). Its average over I is at most 2q/√M after q calls, by Cauchy–Schwarz and ∑_I p_(j,I)≤1. Output probability separation of at least 1/3 requires state distance at least a constant for every I. Hence q=Ω(√M). The verifier's initial trusted information must be independent of the particular oracle; the prover may be arbitrarily powerful subject to the stated soundness on each NO oracle. [Bennett, Bernstein, Brassard and Vazirani, Strengths and Weaknesses of Quantum Computing](https://arxiv.org/abs/quant-ph/9701001)

Using the optimal block partition yields M=B(N). The parity-flip family yields M=2^N, matching the arbitrary-basis witness-verification upper bound. These are query statements and do not require efficient quantum implementations of the uncharged enumeration steps.
