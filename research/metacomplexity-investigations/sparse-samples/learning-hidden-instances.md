# Learning the hidden minimization function

Suppose a simple cubic graph \(G\) on \(n\) named old coordinates is hidden. The learner knows the sparse-example construction, but receives no rows or graph edges. The private coordinates always have read cap two. The learner queries a set \(U\) of old coordinates to give a third read and a gate threshold \(s\); a single Boolean answer says whether a qualifying formula exists. Exact identification means outputting the labeled graph, which represents its entire minimization function. Evaluating the resulting representation on arbitrary new masks is a separate computational problem.

Write \(C=7n-1\), since a cubic graph has \(3n/2\) edges. The answer to a query is \(\alpha(G[U])\ge C-s\) by the main theorem. The same answers result if the oracle requires agreement on the entire cube or uses the two-gate penalty objective.

**Variable thresholds.** The optimal worst-case deterministic query complexity is \(\Theta(n\log n)\), with polynomial running time outside the oracle. Indeed, use \(s=C-|U|\) to test whether \(U\) is independent. For a short algorithm process the vertices in known order and maintain a proper four-coloring of the recovered prefix. For any subset \(S\) of one color class, \(S\cup\{v\}\) is independent precisely when \(v\) has no neighbor in \(S\). Test each nonempty class, then recursively bisect the classes yielding a neighbor. At most three positive branches persist across any depth. This takes \(O(1+3\log n)\) tests per vertex and recovers its earlier neighbors. Assign one of the four colors avoiding those neighbors. For the lower bound use two fixed labeled cycles of length \(b=n/2\ge4\) and one unknown perfect matching between them. There are \(b!\) different graphs. Pair tests distinguish their minimization functions. A binary decision tree therefore needs at least \(\log_2(b!)\) worst-case queries.

The independent-set query is the complement of an edge-detection query. Angluin and Chen proved the general hidden-graph reconstruction bound of \(O(\log n)\) queries per edge. The bounded-degree argument above is included to give a direct implementation of its transfer to formula budgets. [Angluin and Chen, *Learning a hidden graph using O(log n) queries per edge*](https://doi.org/10.1016/j.jcss.2007.06.006).

**One fixed threshold.** At threshold \(C-2\), exact identification instead takes \(\Theta(n^2)\) queries, including for bounded-error randomized algorithms. All pair tests suffice. For the lower bound the same two cycles joined by a matching are triangle-free. Every three-element set contains a nonedge, so all masks of size at least three qualify at this threshold. Masks of size at most one never qualify; only a two-element mask can reveal an unknown adjacency. On the hard family each such query is constant or examines one position of a hidden permutation matrix.

For a direct deterministic bound, answer that a cross edge is absent whenever at least one perfect matching avoids it in the current candidate bipartite graph. Delete it on such an answer; otherwise all surviving perfect matchings contain it and an affirmative answer adds no information. At completion the surviving graph has a unique perfect matching. Contract its pairs and direct each remaining physical edge from its row-pair to its column-pair. A directed cycle would exchange the matching, so at most \(b(b-1)/2\) nonmatching edges remain. At least \(b(b-1)/2\) queried edges have been deleted. For randomization apply the known quadratic lower bound for learning a matching from individual edge queries. [Mande, Sanyal and Zamaraev, *Complexity of learning matchings and half graphs via edge queries*](https://arxiv.org/abs/2507.03151).

More generally fix the threshold \(C-k\), \(k\ge2\). Sets of size at least \(4k-3\) automatically contain an independent \(k\)-set by greedy four-coloring. Every remaining query on the permutation family can be simulated by \(O(k^2)\) individual cross-edge tests, with unlimited internal computation. For \(n\ge4k+1\) the different matching graphs induce different threshold predicates. To distinguish a pair that is an edge in one graph and a nonedge in the other, use an independent \(k\)-set containing the pair in the latter graph: the two closed neighborhoods remove at most eight vertices, leaving an independent set of size at least \(\lceil(n-8)/4\rceil\ge k-2\). The same reduction gives \(\Omega(n^2/k^2)\) queries, including with bounded error.

For every fixed \(k\ge2\), the matching \(O(n^2)\) upper bound holds even without prior knowledge of a single edge. For \(n\ge12k\), greedily extract nine disjoint independent \(k\)-sets as reservoirs. Start each extraction with the whole unused set and repeatedly delete a label if the oracle still accepts. The result is a minimal accepting set, necessarily an independent set of exactly \(k\) vertices. There are enough unused vertices at every start by the four-color bound. To test \(u,v\), try completing them with any fixed \(k-2\) points from each reservoir. If they are adjacent none succeeds. Otherwise their closed neighborhoods occupy at most eight vertices and so miss an entire reservoir, which succeeds. Below the stated size threshold there are only finitely many input lengths for fixed \(k\); an unidentifiable function may then fail to determine the graph, so the reconstruction bound concerns the displayed range.

**A fixed threshold that permits optimal learning.** Augment the hidden graph by \(n\) known disjoint copies of \(K_4\) and distinguish one vertex from each copy. These \(n\) anchors are mutually independent and are disjoint from the unknown component. Call the new size constant \(C'\). To test independence of any \(U\subseteq V(G)\), give third reads to the vertices of \(U\) together with \(n-|U|\) anchors. The fixed threshold \(C'-n\) accepts exactly when the resulting \(n\) vertices are independent, equivalently when \(U\) is independent. No other old or private vertex is enabled. The augmented sample remains linear in \(n\), its row weights and per-coordinate occurrences remain the same, and the adaptive \(\Theta(n\log n)\) bound applies to this single-threshold family.
