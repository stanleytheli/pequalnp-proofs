# Parity classes inside a 2-CNF

For any nonempty solution set \(S\) of a 2-CNF on \(n\geq1\) variables, suppose all solutions have the same parity. Then \(S\) is contained in a set described by disjoint equality or disequality constraints on \(\lfloor n/2\rfloor\) pairs, with one additional pinned bit if \(n\) is odd. Its size is at most \(2^{\lfloor n/2\rfloor}\). Equality holds exactly for these pair patterns themselves.

To prove this, choose \(a\in S\) and set \(T=S\oplus a\). The solutions of a binary clause are closed under coordinatewise majority. If a majority falsifies the two literals, at least two assignments falsify each, so one assignment falsifies both. Unit clauses have the same closure, and intersections preserve it. Coordinatewise complementations preserve majority. Thus \(T\) is majority-closed, contains zero and consists of even words. In particular \(x\cap y=\operatorname{maj}(0,x,y)\) belongs to \(T\) for every \(x,y\in T\), identifying words with their supports.

Let \(L\) be the binary linear span of \(T\). Intersection distributes over symmetric difference, so \(L\) is closed under intersection. It is also closed under union and difference. Every element of \(L\) is even. The nonempty inclusion-minimal members of \(L\) are pairwise disjoint, since a nonempty intersection belongs to \(L\). Every nonempty member contains one such block, and successive differences express it as a union of blocks. Conversely every union of blocks belongs to \(L\). These blocks partition exactly the varying coordinates, and two varying coordinates lie in the same block exactly when their columns agree on \(T\).

Each block has even size. Partition each block into pairs. Pair the constant coordinates too, leaving a single fixed coordinate when \(n\) is odd. Undoing the translation gives one common equality or disequality on each pair. All assignments satisfying the resulting pattern have the original parity. Each pair permits two independent choices. A monochromatic relation attains the bound precisely when it exhausts the containing pattern. Conversely any such pattern is a 2-CNF, since equality and disequality each use two binary clauses and the pin uses a unit clause.

It follows that a union of monochromatic 2-CNF relations covering one parity class needs at least \(2^{\lceil n/2\rceil-1}\) members. A fixed pairing gives equality. For even \(n\), vary all pair signs with the prescribed total parity. For odd \(n\), vary every pair sign and set the unpaired bit to the unique value restoring the prescribed parity. In any minimum cover every member is an entire pair pattern and the members are disjoint. This describes a union of relations or independent witness branches. An application with constraints coupling different branches must check that it can implement them jointly.

For a specified parity the number of distinct maximum patterns is \((2m-1)!!\,2^{m-1}\) when \(n=2m\ge2\), and \((2m+1)!!\,2^m\) when \(n=2m+1\). In a maximum pattern the unique mate of each varying coordinate is recoverable from the solution columns up to complementation. The fixed coordinate in the odd case is also recoverable. Therefore these counts distinguish the actual relations.

## Exhaustive check

Run `python3 -B check.py` and compare with `verification.txt`. Only the Python standard library is used. Through four variables the script constructs **all** 2-CNF relations by successively conjoining all possible unit and binary clauses. It cross-checks each family against testing every Boolean relation for equality with its binary-clause hull. At five variables it tests every nonempty relation contained in either parity class for equality with its hull. For every nonempty monochromatic 2-CNF found, the script verifies the even-block span, containment in an independently generated pair pattern, the cardinality bound and the equality classification.
