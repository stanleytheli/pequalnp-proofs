# Directed Hamiltonicity, parity and deletion to a bipartite graph

## Many maximal false inputs for directed Hamiltonicity

Use the m² possible entries of a 0/1 directed adjacency matrix. The directed Hamiltonian-cycle polynomial over the reals has positive value exactly on Hamiltonian matrices. If an input is a maximal false matrix for this monotone predicate, a CNF clause violated there has a positive literal for every missing arc whose addition creates a tour. This holds even when negated literals are allowed: changing a missing bit from zero to one must make the violated clause true. Distinct maximal false matrices therefore require different clauses. Include every loop in these matrices so that irrelevant diagonal entries create no exceptions.

On m vertices fix r−1 separator vertices and r distinct leaders, with 2≤r and 2r−1≤m. Assign each of the other m−2r+1 vertices to one of the r leaders. Each leader and its followers form a complete directed clique. The separator is a complete clique joined in both directions to every vertex; all arcs between different leader blocks are absent. Removing the r−1 separators from a Hamiltonian cycle would leave at most r−1 path segments, but r distinct blocks need visiting. After adding any arc between distinct blocks, traverse the first clique ending at that arc's tail, use the arc, and traverse the second starting at its head. Join this run and the remaining r−2 clique runs into a cycle through the r−1 separators. Each added arc thus suffices. Distinct assignments are recovered from the neighbor relation to the leaders. The construction gives at least r^(m−2r+1) maximal false matrices. It is a standard separator obstruction to Hamiltonicity; related maximal nonhamiltonian graphs have been studied in graph theory. [Chvátal et al., On maximal nonhamiltonian graphs](https://kam.mff.cuni.cz/~chvatal/2024/wild%20graphs.pdf)

Choose r≈m/log m. The logarithm of the clause lower bound is at least m log m−m log log m−O(m). In particular, a bipartite, cube-preserving affine, positive midpoint-bounded representation of Hamiltonian support requires

    N ≥ exp((1/2−o(1))m log m).

There is also a locality obstruction, independent of graph size. Remove all arcs from a set S to its complement in the otherwise complete directed graph. Every removed arc creates a Hamiltonian cycle when restored, by spanning both sides in two runs. The violated clause therefore has width at least |S|(m−|S|). For balanced S this forces d≥⌈⌊m²/4⌋/2⌉ if each physical probability depends on at most d input coordinates. In particular a one-coordinate bipartite positive border cannot realize Hamiltonian support for m≥4. For m=3 a different maximal false graph can be checked separately; the displayed width bound alone does not settle that order.

## Tight graph order for parity support

A clause whose falsifying assignments are all even must fix every input coordinate, since any free coordinate changes parity. Each such clause rejects at most one corner. A CNF for odd parity on n≥1 bits requires at least 2^(n−1) clauses, so N=Ω(2^(n/2)) for a bipartite midpoint-bounded representation.

A matching-order upper bound uses a graph with one left vertex for each possible assignment on the first ⌊n/2⌋ bits, and one right vertex for each possible assignment on the remaining bits. Join pairs whose total parity is even. Each vertex receives an absence probability equal to the normalized Hamming distance from its stored assignment on its own half. At a Boolean input exactly its two matching records are forced to be present. If they are adjacent, Q=0. Otherwise all remaining vertices can simultaneously be absent with positive probability, so Q>0. This gives at most 2^⌊n/2⌋+2^⌈n/2⌉ vertices for n≥2, with positive unscaled affine probabilities. The construction represents parity support. Multiplicities and values within the continuous cube are not prescribed.

## How many vertices must be deleted to reach bipartiteness?

Let T consist of t vertices whose deletion leaves a bipartition. Use the same good covers and the same nonnegative normalized forms d_v as in the midpoint proof. Split the good covers by membership on T. Within a fixed nonempty class the two bipartite recombination operations on the remaining vertices still give legal covers: all edges incident with T have the same selected endpoint there or require the opposite endpoint in both original covers. The multiplicative weight identity holds as before. Every selected T vertex gives a mandatory D_v=[d_v>0], and the preceding Helly argument applies on the residual bipartition. The support is thus a disjunction of at most 2ᵗ CNFs. Across all branches there is just one shared bank of at most N+binom(N,2) possible clauses, of the forms D_v and D_u OR D_v. Tautologies can be deleted. If every input parameter involves at most d bits, all nonconstant clauses have width at most 2d.

For parity this gives two numerical lower bounds. Every satisfying input of one branch is isolated, because changing any bit changes total parity. The satisfiability coding lemma says that a width-W CNF on n bits has at most 2^(n−n/W) isolated satisfying assignments. For completeness, process the variables in a uniformly random order. For each bit fix a critical clause, one with that literal as its only true one. With probability at least 1/W this bit is last among the clause's variables and is forced by unit propagation at that step, so it can be omitted from an encoding. For each fixed order the resulting code is prefix-free (the decoder knows when all n variables have been assigned). Kraft's inequality and Jensen's inequality give the claimed count. Summing over the 2ᵗ branches and the 2^(n−1) odd inputs yields

    t ≥ n/(2d) − 1.

Even with unrestricted affine locality consider W=⌈log₂(8n(N²+N+1))⌉. For a uniformly random input, a fixed clause of width j>W is critical with probability j2⁻ʲ. Conditioning on odd parity can increase this by at most two. After removing duplicate literals and tautologies, j≤n; the union bound over the *shared* bank shows at least half of all odd inputs have no critical wide clause anywhere. For any such input and its witnessing branch, remove all clauses of width >W. The input still satisfies it and remains isolated: every one-bit change violated some clause, which was critical at the original input and therefore narrow. The same coding argument gives

    t ≥ n/W − 2.

In particular polynomial graph order forces Ω(n/log n) deletions, even if one allows whole-cube affine forms. This conclusion uses sharing of the bank; a count of all branch-clause occurrences would lose this estimate. The coding lemma and its use for parity and ORs of CNFs are classical. [Paturi, Pudlák and Zane, 1997](https://cseweb.ucsd.edu/~paturi/myPapers/pubs/PaturiPudlakZane_1997_focs.pdf) [Emdin, Kulikov, Mihajlin and Slezkin, 2022](https://doi.org/10.4230/LIPIcs.MFCS.2022.47)

## Near-matching constructions with few odd cycles

Split n input bits into k nonempty blocks of size at most b=⌈n/k⌉. Use k logical variables recording the virtual block parities, along with O(k) Boolean variables and constant-arity XOR constraints expressing that the virtual parities XOR to one. Construct an independent-set record graph on O(k) vertices: a two-record clique per Boolean variable, one clique of satisfying tuples per gate, and edges from tuple records to inconsistent variable records. Enforce the output by allowing only its true value. A set can contain at most one record per group. Independent sets meeting every group are exactly the satisfying assignments with their unique tuple records. The virtual parity predicate has at least one such assignment. Set each of the S core probabilities to 1−t. If there are B groups, multiplication by t^−(S−B) retains precisely those maximum sets in the coefficientwise limit t→0.

For each virtual input record labeled e∈{0,1}, attach one new leaf for every assignment a of its physical block with parity different from e. Use its normalized Hamming distance from a as the leaf's absence probability. Integrating that leaf gives the distance factor if the record is selected and 1 otherwise. Thus a retained record has positive product at a Boolean x exactly if its label equals the actual parity of that block. The full positive coefficientwise polynomial limit has support equal to odd parity. Integrating leaves before taking the limit proves coefficientwise finiteness on the entire cube, since every term has at least S−B powers of t. The graph uses O(k2ᵇ) vertices, has affine locality at most b, and becomes an independent set after deleting O(k) core vertices. Taking b≈log n achieves O(n/log n) deletions with polynomial graph order. Taking k≈n/d for any locality 1≤d≤n matches the locality bound up to a constant factor, with the displayed size tradeoff.
