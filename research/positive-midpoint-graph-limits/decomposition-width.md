# Positive limits at bounded graph pathwidth and treewidth

Allow arbitrary underlying graphs, including graphs with odd cycles. Fix polynomial-size graph families, cube-preserving affine vertex probabilities, positive global rescaling, finite convergence on Boolean inputs and boundedness at their midpoint. For nonuniform Boolean supports the following characterizations hold. The convention here permits polynomial advice in each class. Families with coefficientwise polynomial convergence realize all the lower inclusions.

| Restriction on the underlying graph | Boolean support class |
|---|---|
| Pathwidth O(1) | NC¹ |
| Pathwidth O(log n) | NL/poly |
| Treewidth O(1) | NC¹ |
| Treewidth O(log n) | Nonuniform SAC¹, the semi-unbounded fan-in logarithmic-depth class |

The n in these bounds counts Boolean input variables. Nonuniform NC¹ consists of bounded-fanin, polynomial-size Boolean circuits with depth O(log n). A nondeterministic branching program of polynomial length and width defines NL/poly. SAC¹ allows polynomial fan-in for OR, fan-in two for AND, and input literals. Its uniform version characterizes LOGCFL with the usual uniformity conventions. No separation between these classes is assumed. [Barrington](https://doi.org/10.1016/0022-0000(89)90037-8) [Venkateswaran](https://doi.org/10.1145/28395.28411)

## Removing the real weights from a fixed decomposition

Let a_v(j) be vertex v's absence probability at the midpoint, and let D_v be the disjunction describing positive support of its normalized limiting absence form. The midpoint proof gives positivity precisely when some legal cover C has positive limit of c_j∏_{v∈C}a_v(j) and uses only vertices with D_v(x)=true. The common subsequence in this statement depends on the graph family at this input length, never on the particular input x.

For a nice path decomposition of width k, list a cover by its successive choices in the bags, recording a bit at every introduced vertex. Forbid local assignments that leave both endpoints of an edge outside the cover. Forget bits when the vertices leave the bag. Assign a factor a_v(j) once, at the introduce step when v is included. This is a layered acyclic branching program of polynomial length and at most 2^{k+1} concurrent states. Each complete cover has a legal path, with product exactly its midpoint weight before c_j. Assign a single root and sink if needed.

At stage j let B_j(u) be the maximum product of all suffixes from a state u to the sink, with zero for a dead end and one at the sink. For an edge u→v of local weight h_j, store r_j=h_j B_j(v)/B_j(u) if B_j(u)>0, and zero otherwise. These numbers lie in [0,1]. The product along any complete path, multiplied by B_j(root), equals its original weight, including zero-weight paths. Since every cover-absent event is contained in the no-edge event, c_j B_j(root) is bounded at the midpoint. For a nonempty Boolean support it is bounded away from zero eventually: some good cover already has positive limiting weight. Pass to a common subsequence on which all finitely many ratios and c_j B_j(root) converge. A complete path now has positive limiting rescaled weight precisely when every edge on it has a positive limiting ratio. These allowed edges are finite Boolean advice. Put D_v(x) on an allowed edge when it introduces v into the cover, and true otherwise. Nondeterministic reachability in this advised program exactly tests support.

For constant width evaluate the sequence of Boolean transition matrices by a balanced binary product. The matrices have constant dimensions, giving bounded-fanin depth O(log n) after one parallel stage of O(log n) depth for the affine clauses. For width O(log n) of the *graph decomposition*, the branching program width is polynomial. A logspace machine with advice can guess its accepting path, checking a guard disjunction by guessing a literal or scanning its polynomial-size description.

For a tree decomposition use a binary tree of width at most 3k+2, logarithmic depth and polynomially many bags. A graph admits a decomposition with O(N) bags before balancing, and only existence is needed for nonuniform advice. At each bag store cover-selection bits, enforce consistency on overlaps, and assign every edge test and vertex factor to exactly one suitable bag. For each bag state w, its best subtree weight B_j(w) is the maximum over all compatible child-state pairs of the local factor times their two best subtree weights. Add a one-state super-root with a unit transition to each ordinary root state. Its normalization compares each ordinary root weight to their maximum, removing any root state whose total scale vanishes. At leaves a transition has zero children, so its weight is just the local factor. Normalize each transition by B_j(w) as above. A product over a complete derivation telescopes because the two child factors are precisely the denominators at the next level. Zero values can be treated as above, or the identity can be proved by induction on subtrees. The number of states and transitions per bag is 2^O(k). Limiting ratios yield static allowed transitions; the local input guard is the conjunction of D_v for included vertices assigned to the bag. All such guards are precomputed in parallel, with bounded-fanin depth O(log n) at most. Then an OR over compatible transitions and a binary AND of child results and the guard implement one level in constant SAC depth. With constant k the OR itself has bounded fan-in; with k=O(log n) the width and size remain polynomial. This gives the two tree upper inclusions. [Bodlaender and Hagerup, balanced tree decompositions](https://ics-archive.science.uu.nl/research/techreps/repo/CS-1995/1995-25.pdf)

## Encoding a branching-program computation in a narrow graph

A nondeterministic layered Boolean branching program of width W and length s has log₂W-bit state names. Encode consecutive states by two such words and verify legality of their transition. For each possible pair of names a,b, test sequentially whether the two words equal that pair. The tests are deterministic chains of O(log W) gates with bounded fan-in. When equality holds, require that one of the input literals labeling transitions a→b is true. Missing edges have guard false; an unconditional edge has guard true. The disjunction can be represented by the positive support of the average of its literals. The average-of-literals guard handles arbitrarily many labels sharing a pair of states without increasing the number of live states. Initial and final states have fixed acceptance constraints. Reject invalid state codes explicitly.

Convert this finite verification system to a graph. Each Boolean variable has a two-record clique and every constant-arity gate has one clique of its satisfying local tuples. A tuple record is adjacent to any inconsistent value record of its incident variables. Thus an independent set meeting every group is a consistent computation. To enforce a guard when a comparison flag is true, attach a leaf to its true record having absence probability equal to the guard’s affine form. Summing out that leaf contributes the guard exactly when its owner is selected, and 1 otherwise. Set all S core probabilities to 1−t and multiply Q by t^−(S−B), where B is the number of record groups. At most B records can be selected, so the limit exists coefficientwise. Its Boolean support means that some state sequence passes every guard. The number of records is O(s W² log(2W)) when each pair uses one guard. Fixed and boundary bookkeeping changes this by only a polynomial factor.

There is a path decomposition of width O(log(2W)): keep the value records of the two current state words live through all their transition checks, process the private comparison gates one at a time, then forget the older word and introduce the next. Each private gate has only a constant number of records. A transient comparison flag and its guard leaf need only constant extra space. Long incidence lists of a state bit affect the number of bags, not the width. Barrington's theorem supplies constant-width branching programs for every nonuniform NC¹ function. Polynomial-width nondeterministic programs realize NL/poly. This proves the two path lower inclusions, and includes the constant-treewidth lower inclusion.

## Encoding a semi-unbounded proof tree

Take a polynomial-size depth-D SAC¹ circuit, D=O(log n). A true AND has two true children, a true OR has one chosen true child, and a true literal verifies its bit. Use a complete binary certificate tree down to depth D and put a log(s)-bit gate name at each node, where s is the circuit size, with the root forced to name the output. A dummy true gate pads unused child nodes, including the second child of OR nodes and children below leaves. Reserve constant false and true gates with their appropriate literal guards. The local relation between a parent gate name and its two child names is a fixed table. At the bottom require literal, constant or dummy names. Every consistent tree is an accepting proof precisely when its tested literals hold. There are at most 2^{D+1}−1 positions, polynomial in n.

For each position keep the parent and two child name words in one local group, and check all allowed triples by scanning possible names with the same comparison gadgets as above. Forbid any invalid triple, and attach affine literal guards to a literal name when used. There are only polynomially many local checks, and at any point O(log s) record vertices plus constant temporary space suffice. Join the local scanning paths as a tree: attach a child position's first bag to a parent bag containing that child word, and keep the respective boundary word in all bags of its local check. This is a tree decomposition with width O(log n). All probabilities and the output normalization are as in the branching-program encoding. This gives the SAC¹ lower inclusion using only literal or constant affine inputs.

The dynamic programs, bounded-width branching programs and semi-unbounded proof trees are established tools. The conversion of possibly unbounded positive rescalings to static allowed dynamic-program transitions uses the extra midpoint hypothesis. The Boolean-corner-only model can behave differently. The class statements concern support, with one polynomial-size graph and one choice of advice for each input length.
