# A quadratic-size Hamiltonian-cycle witness

There is an explicit subcubic seed and hence an explicit ten-edge-subdivided graph with Θ(m²) vertices for the order-m Hamiltonian-cycle polynomial. The lower-order overhead for verifying ranks uses a sorting network. Each data input appears exactly once. This improves the O(m² log m) occurrence bound for comparing two binary ranks separately on each possible arc.

Set b=ceil(log₂m), M=2ᵇ, and anchor vertex 0 at rank 0. Introduce m² Boolean variables aᵢⱼ and a b-bit rank rᵢ per vertex. Require exactly one aᵢⱼ per row. Obtain the address j of this unique bit in O(m) Boolean gates per row, including the check. Pad the row by constant false bits to length M. For each binary subtree compute its occupancy and the local address of its occupied bit, assigning address zero to an empty block. A parent receives the OR of the child occupancy flags, prohibits both flags, concatenates the right occupancy flag as the high bit and takes componentwise ORs of the lower address words. At height h the cost is O(h) per block, so a row uses O(M Σₕ h/2ʰ)=O(m) gates. Require the root flag to be true.

Compute the modular successor of each rank in O(b) gates by binary increment, with a reset to zero at m−1. The rule outside [0,m−1] is immaterial for accepted assignments. Form the record (j, successor(rᵢ)) for each row i. Pad to M records with a new highest key M. Sort by key. The Batcher bitonic sorting network uses O(M log²M) compare/exchanges. Comparing and exchanging the O(b)-bit key and payload costs O(b) Boolean gates. Thus sorting costs O(m log³m)=O(m²), since (log m)³/m has a finite maximum. Require output positions j=0,…,m−1 to have key j and payload rⱼ. The key requirement ensures that the directed edges form a permutation. Each compare/exchange is deterministic, including ties, and the rank bits are carried as payload. [Batcher, 1968](https://doi.org/10.1145/1468075.1468121)

From vertex 0 the first m successive vertices have ranks 0,1,…,m−1. They are therefore distinct and exhaust the graph. The next vertex has rank 0 and equals vertex 0. This proves that every accepted edge matrix is a single cycle, even though invalid rank codes were allowed as formal witnesses. Conversely, on a single cycle the ranks are forced by traversing it from 0. All internal gates also have a unique evaluation. The witness is therefore parsimonious over arbitrary matrix weights and every characteristic. Standard gate-equivalence clauses produce O(m²) clauses and literal occurrences. The literal triangles, clause flags, degree splitting, affine data leaves and nine private vertices per edge all have constant-factor or linear occurrence overhead. There are m² genuine data ports, proving the claimed Θ(m²) order.

For each m≥3 the cycle polynomial depends on every off-diagonal entry. Any substitution using a separate target variable or its complement at each physical input needs at least m(m−1) input positions. Thus this vertex count has the optimal asymptotic order for this style of reduction.

The executable quadratic_seed.py constructs all gate-equivalence clauses and weighted graphs. Its independent tests exhaust all maps with all possible anchored b-bit labels for m=2,3, and check all permutations with correct/control labels through m=6. The smaller direct-comparison seed remains convenient for physical graph checks at moderately small m.
